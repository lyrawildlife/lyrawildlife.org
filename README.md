# lyrawildlife.org

Sitio institucional de la Asociación Civil Ambiental Lyra Wildlife.

- `sitio/`: lo que se publica (HTML estático, sin compilación). Netlify publica esta carpeta.
- `material/`: marca, fotos, textos y documentos de trabajo. No se publica.
- Cada cambio en la rama `main` se publica solo en lyrawildlife.org.
- Detalles de trabajo en `LEEME.md`.
